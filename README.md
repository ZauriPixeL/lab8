## ลองจองห้อง

1. เลือกจังหวัด เลือกโรงแรมหรือบ้านพัก แล้วดูห้อง กรองจำนวนคน หรือใส่วันที่แล้วกด **ค้นหาห้องว่าง** จากนั้นกด **จองห้องนี้** ถ้ายังไม่ได้เข้าสู่ระบบ เว็บจะเปิดหน้าเข้าสู่ระบบให้
2. กด **กรอกบัญชีทดลอง** แล้วกด **เข้าสู่ระบบ** จะกลับมาที่ห้องเดิม
3. ใส่ชื่อเล่น เลือกวันเข้าและวันออก ตัวอย่างเช่น ห้อง 101 คืนละ 790 บาท พัก 2 คืน รวม 1,580 บาท
4. กด **ยืนยันการจอง** แล้วเปิด **การจองของฉัน** เพื่อดู แก้ไข หรือลบรายการ

| ชื่อผู้ใช้ | รหัสผ่าน |
| --- | --- |
| demo | stay1234 |
| guest2 | stay1234 |

แต่ละบัญชีเห็นเฉพาะรายการของตัวเอง ข้อมูลอยู่ในเบราว์เซอร์ที่ใช้จอง ถ้าเปลี่ยนเครื่องหรือใช้เบราว์เซอร์อื่นจะได้รายการคนละชุด

## เปิดบนเครื่อง

ใช้ Node.js 22.12 ขึ้นไปในสาย 22 หรือ Node.js 24 เปิดโฟลเดอร์โปรเจกต์แล้วรัน

```sh
npm ci
npm run dev
```

เปิดลิงก์ที่ Vite แสดงใน terminal หากต้องการลองเว็บรุ่นที่จะนำขึ้น Cloud ให้รัน

```sh
npm run build
npm run preview
```

ไฟล์ที่ใช้ deploy อยู่ใน `dist/` โปรเจกต์เปิด Mock API ไว้ให้แล้ว หากต้องการเปลี่ยนการตั้งค่า ให้คัดลอก `.env.example` เป็น `.env.local`

## ส่วนที่ใช้จากแต่ละบท

| บท | ใช้ตรงไหน |
| --- | --- |
| 1 | สร้างหน้าเว็บด้วย Vue และ Quasar ใน `src/main.js` |
| 2 | ใช้ grid เรียงการ์ดห้องพัก และเปลี่ยนเป็นคอลัมน์เดียวบนมือถือใน `RoomsPage.vue` |
| 3 | `RoomCard.vue` รับข้อมูลห้องผ่าน props และส่ง event เมื่อกดจอง ส่วน `BookingForm.vue` ใช้ computed คำนวณค่าห้อง |
| 4 | ใช้ QForm และ QInput ในฟอร์มจอง ใช้ QDialog ถามก่อนลบ |
| 5 | Pinia เก็บผู้ใช้ที่เข้าสู่ระบบ สถานที่ ห้องพัก และรายการจองใน `src/stores/` |
| 6 | Axios เรียก Mock API โดยใช้ GET, POST, PUT และ DELETE ใน `src/mock/api.js` |
| 7 | `src/router/index.js` ตรวจสิทธิ์ก่อนเปิดหน้าจอง ส่วน `src/boot/api.js` แนบ token ไปกับคำขอ |
| 8 | ตั้งค่า API ผ่านไฟล์ env เก็บโค้ดบน GitHub และนำไฟล์ที่ build แล้วขึ้น Cloud |

## การตรวจวันจอง

วันออกต้องอยู่หลังวันเข้า ถ้าห้อง 101 มีคนจองตั้งแต่วันที่ 6 ถึงวันที่ 8 คนถัดไปเข้าได้ตั้งแต่วันที่ 8 ตอนแก้ไขวันพัก ระบบข้ามรายการเดิมของผู้จองก่อนตรวจว่าชนกับรายการอื่นหรือไม่

Mock API เก็บรายการจองใน IndexedDB ส่วน token เก็บใน sessionStorage และมีอายุ 8 ชั่วโมง หลังรีเฟรชเว็บจะตรวจ token อีกครั้งก่อนแสดงรายการจอง

## สถานที่และห้องพัก

มีที่พักจำลอง 9 แห่งใน 3 จังหวัด รวม 19 ห้อง เมื่อค้นตามวัน ระบบจะแสดงเฉพาะห้องที่ยังว่างในช่วงนั้น วันที่และจำนวนคนที่เลือกจะติดไปที่ฟอร์มจองแม้ต้องเข้าสู่ระบบระหว่างทาง

- `GET /places` ส่งรายชื่อสถานที่ จำนวนห้อง และราคาเริ่มต้น
- `GET /rooms` รับ placeId, checkIn และ checkOut เพื่อกรองห้องว่าง
- ผังห้องและราคาคือข้อมูลจำลอง
